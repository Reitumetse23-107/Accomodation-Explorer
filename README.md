# Accommodation Explorer

This Flask website explores Francistown accommodation listings and their estimated value.

## Run locally

1. Create and activate a virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Start the website with `python app.py`.
4. Open `http://127.0.0.1:5000` in a browser.

The application reads the scored listing data from `data/listings_scored.json`. The `.venv` environment, Python cache files, local database files, and environment secrets are excluded from Git.
